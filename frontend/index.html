Stock Ledger Principles

• Append-Only: The stock ledger is immutable. Every stock movement is logged as an event.

• Derived Stock: Current stock per product per location is a calculated sum, never directly edited.

• Reversible: Document cancellations issue compensating inverse ledger entries.

StockSense Data Model Architecture
Table: items

id (INTEGER PK) • title (VARCHAR) • description (TEXT) • category (VARCHAR) • is_active (BOOLEAN) • created_at (TIMESTAMP)

Table: stock_ledger

id (INTEGER PK) • product_id (INT) • location_id (INT) • qty_delta (INT) • source_doc_type (VARCHAR) • source_doc_id (INT) • timestamp

Table: stock_levels

id (INTEGER PK) • product_id (INT) • location_id (INT) • quantity (INT) • updated_at (TIMESTAMP)

Tables: receipts & receipt_items / deliveries & delivery_items

Header & Line Item operational documents driving stock ledger movements.
