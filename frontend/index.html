Database Schema Architecture
Table: items

id (INTEGER PK) • title (VARCHAR) • description (TEXT) • category (VARCHAR) • is_active (BOOLEAN) • odoo_ref_id (INTEGER FK) • created_at (TIMESTAMP)

id (INTEGER PK) • sync_action (VARCHAR) • status (VARCHAR) • records_processed (INT) • details (TEXT)
